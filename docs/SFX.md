# Sound effects

Situs memakai suara pendek untuk klik, hover, pindah halaman, filter, buka keranjang, tambah order, sukses, error, dan drag/rotate model 3D. Tanpa file kustom, situs memakai suara bawaan yang halus (dibuat lewat WebAudio, tanpa file). Pengunjung bisa mematikannya lewat tombol speaker di header.

Ganti dengan suara sendiri: **Admin → Site editor → Sound effects** → upload MP3/OGG/WAV (di bawah 1 MB, makin pendek makin bagus) → Publish.

## Prompt untuk ElevenLabs (Sound Effects)

Buat satu per satu, durasi 0.5–1 detik (hover dan click boleh 0.5 detik), lalu download dan upload di admin.

| Event | Prompt |
|---|---|
| click | Short crisp UI button click, soft tactile tick, close-mic, very brief |
| hover | Very quiet tiny soft UI hover tick, subtle high pop, extremely brief |
| nav | Quick soft airy whoosh swipe, short page transition, smooth |
| toggle | Small switch toggle snap, soft plastic click, short |
| open | Smooth sliding panel opening, short air swish ending with a soft thud |
| add | Soft bubbly pop with a short rising blip, satisfying add to cart |
| success | Bright short positive chime, two soft ascending glassy notes, game reward ding |
| error | Short low muted error buzz, soft double thud, gentle denied sound |
| drag | Gentle dial scrub, short soft friction swish, turning a smooth knob |
